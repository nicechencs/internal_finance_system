🔍 路由切换问题诊断报告

问题分析

❌ 问题 1: el-menu 的 router 模式可能存在问题

当前配置：

<el-menu :default-active="activeMenu" router class="sidebar-menu">

问题描述：Element Plus 的 router 属性会自动将 index 作为路由路径进行跳转，但这可能与 Vue Router 的导航守卫产生冲突。

症状：点击菜单项时，URL 改变但页面内容不更新。

⚠️ 问题 2: activeMenu 计算属性可能不够精确

当前代码：

const activeMenu = computed(() => route.path)

潜在问题：对于带参数的路由（如 /accounts/:id），route.path 会返回完整路径（如 /accounts/123），但菜单项的 index 是 /accounts，导致菜单高亮不正确。

⚠️ 问题 3: 路由守卫可能阻止导航

当前守卫：

router.beforeEach((to, from, next) => {
  // 检查认证和权限
  if (to.meta.requiresAuth && !userStore.isLoggedIn()) {
    next('/login')
    return
  }
  // ...
})

潜在问题：如果 userStore 状态异常或权限检查逻辑有误，可能导致导航被阻止。

❌ 问题 4: 组件可能没有正确响应路由变化

症状：路由改变但组件内容不更新。

原因：Vue Router 在相同组件间切换时，默认会复用组件实例，不会触发 onMounted 等生命周期钩子。

需要检查：组件是否使用了 watch(route, ...) 或 onBeforeRouteUpdate 来响应路由参数变化。

推荐修复方案

✅ 方案 1: 改用手动导航（推荐）

移除 router 属性，改用 @select 事件手动导航：

<el-menu
  :default-active="activeMenu"
  @select="handleMenuSelect"
  class="sidebar-menu"
>

const handleMenuSelect = (index: string) => {
  router.push(index)
}

优点：完全控制导航逻辑，避免 Element Plus 和 Vue Router 的冲突。

✅ 方案 2: 优化 activeMenu 计算

改进菜单高亮逻辑，支持带参数的路由：

const activeMenu = computed(() => {
  const path = route.path
  // 处理详情页等带参数的路由
  if (path.startsWith('/accounts/') && path !== '/accounts') return '/accounts'
  if (path.startsWith('/customers/') && path !== '/customers') return '/customers'
  if (path.startsWith('/suppliers/') && path !== '/suppliers') return '/suppliers'
  if (path.startsWith('/persons/') && path !== '/persons') return '/persons'
  if (path.startsWith('/projects/') && path !== '/projects') return '/projects'
  if (path.startsWith('/receivables/') && path !== '/receivables') return '/finance'
  if (path.startsWith('/payables/') && path !== '/payables') return '/finance'
  return path
})

✅ 方案 3: 添加路由变化监听

在需要响应路由变化的组件中添加：

import { watch } from 'vue'
import { useRoute } from 'vue-router'

const route = useRoute()

watch(() => route.params, (newParams) => {
  // 重新加载数据
  loadData()
}, { immediate: true })

✅ 方案 4: 添加路由调试日志

在路由守卫中添加调试信息：

router.beforeEach((to, from, next) => {
  console.log('🔄 路由导航:', {
    from: from.path,
    to: to.path,
    isLoggedIn: userStore.isLoggedIn(),
    userRole: userStore.user?.role
  })
  // ... 原有逻辑
})

检查清单

  • ✅ 检查浏览器控制台是否有 JavaScript 错误
  • ✅ 检查 Network 面板，确认 API 请求是否正常发送
  • ✅ 检查 Vue DevTools 中的路由状态和组件树
  • ✅ 检查 localStorage 中的 token 是否有效
  • ✅ 检查用户权限是否正确配置
  • ✅ 测试不同角色用户的菜单访问

快速测试步骤

  1. 打开浏览器开发者工具（F12）
  2. 切换到 Console 标签
  3. 点击侧边栏菜单项
  4. 观察：
    • URL 是否改变？
    • 是否有错误信息？
    • 是否有路由导航日志？
    • Network 面板是否有新的 API 请求？
  5. 在 Vue DevTools 中检查：
    • 当前路由信息（Router 标签）
    • 组件是否重新渲染（Components 标签）
    • Pinia store 状态（Pinia 标签）
