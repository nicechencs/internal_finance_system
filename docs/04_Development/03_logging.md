# 日志规范

状态：Active
适用对象：开发 / 运维
事实源级别：Primary
最后核对日期：2026-03-21
来源：由旧版日志规范整理

## 目标

- 便于排查问题
- 减少重复与噪音
- 避免泄露敏感信息

## 基本原则

- 记录关键业务节点
- 记录异常上下文
- 不记录密码、完整敏感凭证、完整卡号等敏感信息

## 建议保留的日志内容

- 用户、角色、批次、实体 ID 等可追溯上下文
- 导入、规则重跑、关联确认、部署健康检查等关键动作
- 错误原因与关键参数
