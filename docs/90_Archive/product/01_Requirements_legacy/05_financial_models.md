# 财务业务模型

## 项目收入结构

字段：
- 合同金额
- 已收金额
- 应收金额

计算公式：

应收金额 = 合同金额 - 已收金额

## 成本分类

开发成本
- 开发人员工资
- 外包开发费用
- 开发工具
- 云服务器

实施成本
- 客户部署
- 技术支持

运维成本
- 服务器运维
- 运维人员

公司运营成本
- 办公用品
- 硬件设备
- 软件订阅

售前成本
- 差旅
- 商务沟通
