# 系统架构设计

## 架构结构

前端（Vue）
↓
后端 API
↓
业务服务层
↓
数据库

## 推荐技术栈

### 后端
- .NET 8
- ASP.NET Core Web API
- EF Core

### 前端
- Vue3
- Vite
- Element Plus
- Pinia

### 数据库
- PostgreSQL

### 部署
- Docker
- Nginx

## 技术选型原因

### .NET
- 数据建模能力强
- LINQ 查询适合财务统计
- AI 辅助生成代码质量高

### Vue
- 后台系统生态成熟
- 表格组件丰富
- 适合管理系统开发
