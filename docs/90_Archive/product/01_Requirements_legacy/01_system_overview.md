# 财务管理系统概述

## 系统目标
该系统是一个 **财务管理系统**，用于公司负责人掌握真实经营情况，而不是用于税务申报。

核心目标：
- 管理公司真实资金流
- 管理项目收入与成本
- 管理应收与应付
- 分析人员、供应商成本
- 生成经营分析报表

## 系统特点
- Web 系统
- 通过 Excel 导入银行流水（仅支持 .xlsx 格式）
- 支持项目维度的财务分析
- 支持自动分类与规则匹配
- 初期主要供管理者个人使用

## 支持账户
- 对公银行账户
- 对公支付宝账户

## 数据来源
交易数据主要通过 Excel 导入（通常每月或每季度一次）。

支持格式：
- .xlsx（Excel 2007 及以上版本）
- 不支持 .xls（Excel 97-2003），需手动转换为 .xlsx

## 技术方向
后端：
- .NET 8（推荐）或 Go

前端：
- Vue3 + TypeScript

数据库：
- PostgreSQL（推荐）
