# 生产环境部署检查清单

使用本清单确保部署过程中不遗漏任何关键步骤。

## 部署前检查

### 服务器环境

- [ ] 服务器操作系统：Ubuntu 20.04+ / Debian 11+
- [ ] 内存：至少 2GB RAM
- [ ] 磁盘空间：至少 20GB 可用
- [ ] Docker 已安装：`docker --version`
- [ ] Docker Compose 已安装：`docker-compose --version`
- [ ] Docker 服务运行中：`systemctl status docker`

### 网络配置

- [ ] 服务器可通过 SSH 访问
- [ ] 防火墙已配置（端口 22, 80, 443, 5000）
- [ ] 域名已解析到服务器 IP（如使用域名）
- [ ] SSL 证书已准备（如使用 HTTPS）

### 服务器目录结构

- [ ] 部署目录已创建：`/opt/finance`
- [ ] 日志目录已创建：`/opt/finance/logs`
- [ ] 备份目录已创建：`/opt/finance/backups`
- [ ] 脚本目录已创建：`/opt/finance/scripts`

### 配置文件

- [ ] `docker-compose.prod.yml` 已下载
- [ ] `.env.production` 已配置
- [ ] `.env.production` 权限设置为 600
- [ ] 所有脚本已下载并赋予执行权限

### 环境变量配置

- [ ] `GITHUB_REPO_OWNER` 已设置
- [ ] `DB_PASSWORD` 已设置（强密码）
- [ ] `BOOTSTRAP_ADMIN_PASSWORD` 已设置
- [ ] `CORS_ALLOWED_ORIGIN` 已设置
- [ ] 端口配置已确认（API_PORT, WEB_PORT）

### SSH 密钥

- [ ] SSH 密钥对已生成
- [ ] 公钥已添加到 `authorized_keys`
- [ ] 私钥已复制（用于 GitHub Secrets）
- [ ] SSH 连接测试成功

## GitHub 配置检查

### 代码仓库

- [ ] `production` 分支已创建
- [ ] `production` 分支代码已同步
- [ ] `.github/workflows/deploy-production.yml` 已提交

### GitHub Secrets

- [ ] `SSH_HOST` 已配置
- [ ] `SSH_PORT` 已配置
- [ ] `SSH_USER` 已配置
- [ ] `SSH_PRIVATE_KEY` 已配置（完整内容）

> 数据库密码等运行时配置在服务器 `.env.production` 中管理，无需配置为 GitHub Secrets。

### 权限设置

- [ ] GitHub Actions 已启用
- [ ] 仓库 Packages 权限已启用（用于 GHCR）
- [ ] 分支保护规则已配置（可选）

## 首次部署检查

### 部署前

- [ ] 本地代码已提交并推送
- [ ] `production` 分支已合并最新代码
- [ ] 服务器磁盘空间充足（至少 10GB 可用）
- [ ] 服务器内存充足（至少 1GB 可用）

### 部署过程

- [ ] GitHub Actions 工作流已触发
- [ ] 镜像构建成功（前端 + 后端）
- [ ] 镜像推送成功（GHCR）
- [ ] SSH 连接成功
- [ ] 镜像拉取成功
- [ ] 容器启动成功

### 部署后验证

- [ ] 数据库容器运行中：`docker ps | grep finance_db`
- [ ] API 容器运行中：`docker ps | grep finance_api`
- [ ] 前端容器运行中：`docker ps | grep finance_web`
- [ ] 健康检查通过：`./scripts/health-check.sh`
- [ ] 数据库连接正常
- [ ] API 响应正常：`curl http://localhost:5000/health`
- [ ] 前端可访问：`curl http://localhost/`

### 功能测试

- [ ] 前端页面加载正常
- [ ] 登录功能正常
- [ ] API 接口响应正常
- [ ] Swagger 文档可访问
- [ ] 数据库初始化成功
- [ ] 管理员账户可登录

## 安全加固检查

### SSH 安全

- [ ] SSH 密钥认证已启用
- [ ] 密码登录已禁用（可选）
- [ ] SSH 端口已修改（可选）
- [ ] Fail2ban 已安装（可选）

### 防火墙

- [ ] UFW 已启用
- [ ] 仅必要端口已开放
- [ ] 未使用端口已关闭

### 应用安全

- [ ] 数据库密码使用强密码
- [ ] CORS 配置正确（生产域名）
- [ ] 管理员密码已修改（不使用默认密码）

### SSL/TLS（如使用 HTTPS）

- [ ] SSL 证书已安装
- [ ] HTTPS 重定向已配置
- [ ] 证书自动续期已配置

## 使用说明

1. **首次部署**：按顺序完成所有检查项
2. **日常部署**：重点检查"部署前检查"和"部署后验证"
3. **问题排查**：参考未通过的检查项进行故障定位
