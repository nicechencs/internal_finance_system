# 应收应付管理页面筛选功能测试计划

## 测试日期
2026-03-14

## 测试目标
验证 FinanceManagement 页面的统一筛选功能是否正常工作，确保筛选条件能够正确传递到子组件并更新列表数据。

## 测试环境
- 前端：Vue3 + TypeScript + Vite + Element Plus
- 后端：.NET 8 + PostgreSQL
- 浏览器：Chrome/Edge 最新版本

## 功能概述
在应收应付合并管理页面（FinanceManagement.vue）中，将筛选条件从子组件（ReceivableList/PayableList）移到父组件，实现统一的筛选入口。

### 主要改动
1. 在 FinanceManagement.vue 的 Tab 下方添加统一筛选表单
2. 根据当前 Tab（应收/应付）动态切换"客户"/"供应商"字段
3. 通过 props 将筛选条件传递给子组件
4. 子组件接收外部筛选条件并应用到 API 请求

## API 请求验证

### 验证点
1. 打开浏览器开发者工具 Network 面板
2. 执行筛选操作
3. 检查 API 请求参数

### 应收账款 API 请求示例
```
GET /api/receivable?page=1&pageSize=20&projectId=1&customerId=2&status=pending&startDate=2026-01-01&endDate=2026-03-31
```

### 应付账款 API 请求示例
```
GET /api/payable?page=1&pageSize=20&projectId=1&supplierId=3&status=pending&startDate=2026-01-01&endDate=2026-03-31
```

### 参数验证
- `projectId`: 数字类型，可选
- `customerId`: 数字类型，可选（仅应收）
- `supplierId`: 数字类型，可选（仅应付）
- `status`: 字符串类型，可选（pending/partial/settled）
- `startDate`: 日期字符串（YYYY-MM-DD），可选
- `endDate`: 日期字符串（YYYY-MM-DD），可选

## 后续优化建议

### 1. TransactionList 筛选增强（优先级：中）
- 添加账户筛选
- 添加分类筛选
