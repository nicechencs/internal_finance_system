三、数据关联关系参考
================================================================================

  账户 (accounts)
    ├─ 交易记录 (transactions)        — 通过 AccountId
    └─ 银行流水 (bank_transactions)   — 通过 AccountId

  客户 (customers)
    ├─ 项目 (projects)                — 通过 CustomerId
    ├─ 应收记录 (receivables)          — 通过 CustomerId
    └─ 交易记录 (transactions)        — 通过 CustomerId

  供应商 (suppliers)
    ├─ 应付记录 (payables)            — 通过 SupplierId
    └─ 交易记录 (transactions)        — 通过 SupplierId

  人员 (persons)
    ├─ 交易记录 (transactions)        — 通过 PersonId
    └─ 分摊记录 (transaction_allocations) — 通过 PersonId

  项目 (projects)
    ├─ 交易记录 (transactions)        — 通过 ProjectId 或 Allocations
    ├─ 应收记录 (receivables)          — 通过 ProjectId
    ├─ 应付记录 (payables)            — 通过 ProjectId
    └─ 分摊记录 (transaction_allocations) — 通过 ProjectId
