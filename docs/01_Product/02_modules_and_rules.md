# 模块与业务规则

## 核心模块

### 账户管理

- 管理银行账户、支付宝账户、定期存款等资金账户。
- 维护期初余额、当前余额、账户统计和定期存款到期提醒。

### 交易管理

- 系统核心事实表，支持收入、支出、转账、关联对象、关联项目和分摊。
- 支持交易详情、账户 / 项目 / 客户 / 供应商 / 人员维度查询、统计和相关财务记录查看。
- 多个展示交易的页面已支持点击行查看交易详情。

### 导入与对账

- 支持银行 / 第三方流水 Excel 导入、预览、去重、确认导入、批次追踪。
- 支持分类规则匹配、手动重跑预览与确认。
- 支持一键关联、批量智能关联和人工确认关联。

### 主数据

- 维护账户、分类、项目、客户、供应商、人员、系统配置。
- 为交易、导入、报表、应收应付和自动关联提供基础信息。
- 客户、供应商、人员已包含银行信息等扩展字段；人员交付 / 验收记录仍待开发。

### 应收应付

- 跟踪待收待付金额，支持分次收款、分次付款、账龄、趋势和统计。
- 支持应付款类型、应收业务类型。
- 客户、供应商、人员、项目详情页可查看应收 / 应付记录和财务概览。

### 标签与规则

- 标签定义、绑定与解绑支持交易、项目、人员、客户、供应商五类实体。
- 标签筛选、统计和交叉分析已实现。
- 标签规则当前用于交易自动打标，支持金额区间、匹配条件和批量重跑。
- 标签每日汇总快照已有数据结构，生成 / 查询能力仍待后续补齐。

### 报表与仪表盘

- 仪表盘支持摘要、月度统计、分类统计、近期交易。
- 后端已提供项目利润、月度利润、现金流、人员成本、供应商支出、年度总览等报表接口。
- 前端独立报表页仍待接入，目前用户侧主要通过仪表盘和详情页查看分析信息。

### 系统管理

- 用户管理、角色权限、数据权限、审计日志、系统配置。

## 关键业务规则

### 交易是核心事实

- 导入的银行流水会映射为交易记录。
- 报表、项目利润、应收应付核销最终都围绕交易记录展开。

### 分摊是关键不变量

- 一笔交易可以分摊到多个项目或人员。
- `is_allocated` 与分摊记录必须一致。
- 分摊金额总和必须等于原交易金额。

### 应收与应付是跟踪型数据

- 应收应付不是取代交易，而是跟踪待收待付状态。
- 收款 / 付款记录可关联具体交易。
- 结算记录与交易绑定需要避免重复绑定和空绑定。

### 转账需要成对处理

- 转账不是普通收入 / 支出。
- 系统支持创建配对转账交易与识别转账候选。

### 自动规则需要人工可控

- 分类规则和标签规则都支持预览与确认。
- 新增规则不会默认对历史数据自动全量重跑，避免批量改写历史记录。
