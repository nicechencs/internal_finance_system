# 功能状态清单

状态：Active  
适用对象：产品 / 开发 / 测试 / AI  
事实源级别：Primary  
最后核对日期：2026-08-17  
代码依据：`backend/FinanceApp.Application/Modules`、`backend/FinanceApp.Api/Controllers`、`frontend/src/features`、`backend/tests`、`frontend/tests`

## 已完成功能

### 基础与权限

- Cookie 会话认证、登录 / 登出、当前用户信息、密码修改。
- 用户管理、角色控制、数据权限过滤、审计日志。
- 系统配置、站点名称自定义、默认开发管理员、演示数据初始化。

### 主数据

- 账户、分类、客户、供应商、人员、项目管理。
- 客户 / 供应商 / 人员银行信息与基础扩展字段。
- 项目编号自动生成、项目收款计划初始化、项目财务汇总。
- 定期存款管理、到期提醒、支取日期校验。
- 标签定义、绑定、解绑、筛选、统计、交叉分析。

### 交易处理

- 交易新增、编辑、删除、查询、统计。
- 收入、支出、转账、分摊、账户余额联动。
- 交易详情页和多页面交易详情弹窗访问。
- 待分配交易入口、交易绑定、相关财务记录查询。
- 待分配交易处理闭环：列表按未完全核销筛选、关联已有应收/应付、创建新单并核销、批量创建并核销。

### 导入与对账

- 银行 / 第三方流水导入、预览、去重、确认导入、批次追踪。
- 分类规则匹配、规则手动重跑预览与确认。
- 标签规则定义、自动打标、批量重跑。
- 一键关联、批量智能关联、人工确认关联。

### 财务结算

- 应收、应付、收款、付款、分次结算。
- 应付款类型管理、应收业务类型管理。
- 应收 / 应付详情页、列表页、图表空数据状态。
- 客户、供应商、人员、项目详情页的应收 / 应付记录和财务概览。
- 结算记录与交易绑定强约束，避免重复绑定。

### 报表与仪表盘

- 仪表盘摘要、月度统计、近期交易。
- 项目利润、月度利润、现金流、人员成本、供应商支出、年度总览。
- 标签分析页跳转交易筛选。

### 工程与架构

- 后端 Application 层按 6 个业务模块组织。
- 后端 Controllers 按业务模块分组。
- 前端按 `features/` 组织 9 个业务模块，并拆分模块路由。
- 后端、前端、基础设施测试均已有覆盖。
- 移动端体验：抽屉导航、语义 token 覆盖、筛选抽屉、高频列表卡片化（工作台 / 交易 / 应收 / 应付），其余页面表格横向滚动兜底。
